# About

NVM for Windows is a Node.js version manager built for Microsoft Windows. It installs, switches, and removes Node.js runtimes so one machine can use many versions without fighting the official single-install Windows installer.

Since 2014 it has been the trusted way tens of millions of Windows developers keep LTS, current, and older versions side by side for apps, CI, and day-to-day work.

## The problem

Node.js was designed for one installation per machine. The official installer replaces or blocks parallel installs. Real projects do not stay on one version line forever: different apps pin different engines, libraries drop support on EOL releases, and teams still need to reproduce bugs on older runtimes.

Without a version manager, that means reinstalling Node by hand and losing time. NVM for Windows makes the active runtime available, simply, in a controlled way.
